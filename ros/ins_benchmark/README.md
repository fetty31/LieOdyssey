# ins_benchmark

ROS 2 Humble benchmark package for replaying dataset measurements through ROS topics to an external `ins_ros` lifecycle node and collecting the output via `/dump_state_history`.

## Features

- dataset-agnostic benchmark core
- ROS 2 topic playback for IMU/GPS/odom inputs
- `/clock` automation for deterministic timestamps
- lifecycle configuration/activation for `ins_ros`
- service call to `/dump_state_history` for saving results to a CSV file
- result metadata written to JSON for downstream evaluation

## Example

```bash
source /opt/ros/humble/setup.bash
colcon build --packages-select ins_benchmark
source install/setup.bash
ros2 run ins_benchmark ins_benchmark --config $(pwd)/src/LieOdyssey/ros/ins_benchmark/config/benchmark_config.yaml
```

The runtime is intentionally designed to interact with `ins_ros` as a black-box ROS 2 component.
