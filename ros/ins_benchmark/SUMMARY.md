# ins_benchmark summary

This package is a ROS 2 Humble benchmark framework designed to replay dataset measurements against the external `ins_ros` estimator through ROS communication.

## Goal

The benchmark is intentionally black-box: it does not depend on the internal C++ implementation of `ins_ros` and instead interacts with it using ROS 2 interfaces only.

The intended execution flow is:

1. load a dataset sequence via a dataset adapter
2. convert dataset samples into common sensor representations
3. publish them on ROS topics
4. advance `/clock` according to dataset timestamps
5. configure and activate the `ins_ros` lifecycle node
6. call `/dump_state_history` to save the estimator result
7. evaluate the saved trajectory/state history against ground truth

- `ins_benchmark/` : package root

  - `benchmark_node.py` : runtime entry point
  - `cli.py` : CLI wrapper

  - `estimators/` : estimator adapters

## ROS 2 interfaces used

- lifecycle services: `change_state`
- sensor topics: IMU, GPS, odometry
- `/clock` for deterministic timestamp playback
- `/dump_state_history` service provided by `ins_ros`
- saved result files for later analysis
